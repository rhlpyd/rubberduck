  • rule 3 - return a more meaningful data - keep the context clean
  • rule 4 - validate input and output. output descriptive errors.
  • MCP - makes tool use scalable and interoperable
  • inspired by LSP

  • results - structured, unstructured( sometimes jusnt return url to prevent context bloat)
  • errors - standard JSON RPC protocol errors - errors during tools execution - server sends result with error flag
