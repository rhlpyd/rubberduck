Here is a short lesson on mounting disk partions in Linux.

Identify partitions

$ lsblk
NAME   MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
sda      8:0    0 931.5G  0 disk 
├─sda1   8:1    0 224.6G  0 part /
├─sda2   8:2    0   8.2G  0 part [SWAP]
├─sda3   8:3    0 232.8G  0 part 
└─sda4   8:4    0 465.8G  0 part 
sdb      8:16   0   1.8T  0 disk 
└─sdb1   8:17   0   1.8T  0 part /media/x/gli

Mounting NTFS partitions

To mount NTFS partitions make sure you have ntfs-3g

$ sudo apt install ntfs-3g

Mounting with udisksctl

$ udiskctl mount -b /dev/sda4

Here is how to unmount.

$ udiskctl unmount -b /dev/sda4

Automount at boot time

If you want to automatically mounnt at boot time you will need to add an entry in /etc/fstab

Here is an example. Add the following line to /etx/fstab

UUID=1A2B3C4D5E6F7890  /mnt/windows  ntfs-3g  defaults,uid=1000,gid=1000,umask=022  0  0

Explanation:

  • UUID=…: Refers to the NTFS partition
  • /mnt/windows: Mount point
  • ntfs-3g: Filesystem driver for NTFS
  • defaults,uid=1000,gid=1000: Mount with your user’s UID/GID (replace with your actual UID/GID if not 1000)
  • umask=022: Sets permissions (readable by everyone, writable only by owner)
  • 0 0: No dump, no fsck on boot

Use the following command to find your UID and GID

$ id

To mount without rebooting

sudo mount -a
