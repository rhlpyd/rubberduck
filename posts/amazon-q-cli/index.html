Amazon Q CLI: Your AI-Powered Command Line Assistant

Amazon Q CLI is a powerful command-line interface that brings AI assistance directly to your terminal. Built by AWS, it provides intelligent help for development tasks, AWS resource management, and general productivity workflows.

Core Features

Interactive Chat Interface - Engage in natural conversations with AI directly from your terminal using q chat.

File System Operations - Read, write, and manage files and directories with intelligent assistance for code editing and file manipulation.

AWS Integration - Execute AWS CLI commands and manage cloud resources with AI guidance and best practices.

Bash Command Execution - Run shell commands with AI recommendations and safety checks for system operations.

Conversation Management - Save and load chat sessions using /save and /load commands for continuity across work sessions.

Agent System - Create custom AI agents with specific roles, tools, and permissions for specialized workflows.

Context Management - Add files and directories to conversation context using /context commands for better AI understanding.

Knowledge Base - Store and retrieve information across sessions with semantic search capabilities (experimental feature).

Key Commands

The CLI offers several slash commands for enhanced functionality:

  • /quit - Exit the application
  • /clear - Clear conversation history
  • /agent - Manage and switch between custom agents
  • /context - Add/remove files and directories from conversation context
  • /save and /load - Persist and restore conversations
  • /tools - View available tools and permissions
  • /experiment - Toggle experimental features like knowledge base and thinking mode
  • /todos - Create and manage task lists
  • /compact - Summarize conversations to free up context space

Practical Examples

Development Workflow

# Start Q CLI and add project context
q chat
/context add ./src
/context add README.md

# Ask for code review or debugging help
"Review this Python function for potential issues"

AWS Resource Management

# Get help with AWS operations
"List all S3 buckets in us-east-1 region"
"Create a Lambda function with Python runtime"
"Show EC2 instances that are running"

File Operations

# Intelligent file management
"Create a Python script that processes CSV files"
"Refactor this JavaScript code to use modern ES6 syntax"
"Generate a README file for this project"

Custom Agents

# Create specialized agents for different tasks
/agent create code-reviewer
/agent create aws-architect
/agent switch documentation-writer

Knowledge Management

# Enable experimental knowledge feature
/experiment
# Add project documentation to knowledge base
/knowledge add ./docs
# Search across stored knowledge
"What did we decide about the API design?"

Installation

Amazon Q CLI is available for multiple platforms:

  • macOS: Download the DMG installer
  • Linux: Available as Ubuntu/Debian packages, AppImage, or alternative builds
  • Development: Clone from GitHub and build with Rust toolchain

Advanced Features

MCP Server Integration - Connect with Model Context Protocol servers for extended functionality and tool integration.

Experimental Features - Access cutting-edge capabilities like persistent knowledge storage, complex reasoning with thinking mode, and tangent conversations.

Configurable Tool Permissions - Fine-tune which tools can access specific paths, commands, or AWS services for security.

Multi-Model Support - Choose from different AI models for varied conversation styles and capabilities.

The Amazon Q CLI transforms your terminal into an intelligent workspace, combining the power of AI with practical development tools. Whether you’re debugging code, managing AWS infrastructure, or organizing project workflows, it provides contextual assistance that adapts to your specific needs.
